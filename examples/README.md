# Приклади

- [`order-card.md`](order-card.md) — поля однієї мікрозадачі в плані. Ведучий заповнює їх до старту, перевіряльник
  звіряє результат саме з ними. Це атом усієї системи: кожна вимога людини стає такою карткою з критерієм готовності
  й методом перевірки.

## Як подивитися систему в дії

Робочих прогонів із даними проєктів тут немає (вони приватні). Що можна зробити з цього репозиторію:

```bash
# 1. Переконатися, що ядро працює — 498 тестів, без сторонніх пакетів (~2 хв):
python3 -m unittest discover -s 00_FORGE/tests

# 2. Подивитися правила системи — пронумеровані K1–K40:
less 00_FORGE/CONSTITUTION.md

# 3. Подивитися реєстр хуків, воріт і скриптів:
less 00_FORGE/TOOLS.md
```

Живий прогін — від постановки задачі до перевіреного результату — показую на співбесіді.
