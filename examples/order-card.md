# Мікрозадача в плані — які поля в ній є

Ведучий заповнює ці поля до старту. Перевіряльник звіряє результат саме з ними.

| Поле | Що туди пишеться |
|---|---|
| Вимога людини | дослівна цитата, з якої виросла задача |
| Критерій готовності | що має бути правдою в кінці |
| Метод перевірки | скрипт, перевірка з бібліотеки або читання перевіряльником — і де лежатиме доказ |
| Межі | які файли задача може змінювати (з лімітом кількості) |
| Модель | на якій моделі йде виконавець |
| Пакет контексту | що харнес передає виконавцю: лише потрібні файли й факти |
| Залежності | які задачі мають завершитись раніше; без залежностей і з різними межами — паралельно |
