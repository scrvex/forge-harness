# Инструкция: как пользоваться Forge (плагин {{KERNEL_VERSION}})

Forge — **плагин к Claude Code / Cowork**, который под вашу сложную задачу собирает рабочее пространство и ведёт в нём
работу: задачи с критериями готовности и проверками, черновая работа на локальной модели, суждение — Claude.
Учится не модель, а система вокруг неё. Forge не заменяет Claude и готовые плагины Cowork — он дополняет их там,
где нужны ваши данные, ваши правила и проверяемый след.

## 0. Когда что использовать
| задача | чем делать |
|---|---|
| рутинный маркетинг, аналитика, почта, календарь, CRM — стандартные инструменты | Cowork с плагинами и коннекторами |
| один результат: страница, игра, документ, постер, схема, скрипт | обычный Claude (в проекте Forge — фраза «сделай мне …») |
| сложная задача на месяцы со своими данными и правилами; высокая цена ошибки | **Forge** |

## 1. Установка (один раз)
1. Убедитесь, что установлены Python 3.12 (команда `python`) и, для дешёвого режима, Ollama с моделью `gemma4:12b`.
2. В терминале Claude Code:
   `claude plugin marketplace add C:/ai/agi` и затем `claude plugin install forge@forge-dev`
   (или откройте папку `C:\ai\agi` в Claude Code — она сама предложит включить плагин).
3. Проверка: в любом проекте Forge при старте появляется строка `[Forge] … plugin {{KERNEL_VERSION}} …`.

## 2. Как начать (в чате с Claude Code, открыв любую папку)
1. Напишите **«привет, что ты умеешь»** — ведущий ответит простыми словами и задаст три вопроса.
2. Опишите задачу словами («я инвестор, хочу стратегию …»). Ведущий проведёт интервью — пока картина не будет полной, —
   перескажет задачу, предложит структуру и первые задачи. Скажите «да, собирай» или поправьте.
3. Перед первой задачей ведущий спросит **режим**: *дешёвый* — черновую работу делает локальная модель (Ollama)
   на вашем компьютере, бесплатно; *дорогой* — всё делает Claude. Ответьте одним словом.
4. Проект появится в отдельной папке (например `C:\ai\<имя>`) с двумя папками: `01_PROJECT_CORE` (ядро 2 под вашу
   задачу — учится) · `02_Для_пользователя` (ваши разделы, документы в PDF, инструкция). Ядро 1 — это сам плагин,
   его номер версии записан в `forge.json` проекта.
5. Дальше работайте фразами из инструкции проекта. Когда базовая настройка закончена, ведущий сообщит об этом —
   папку можно перенести куда угодно и работать в ней отдельно (плагин остаётся установленным).

## 3. Что вы получаете
- Понятную папку под задачу с навигацией и инструкцией простыми словами.
- Работу задачами: цель, критерии готовности и планка качества (вы утверждаете один раз), исполнение, автоматические
  проверки, проверка вторым актёром, отчёт.
- Автоматизацию рутины: всё, что делается дважды, становится скриптом или командой-фразой.
- Самообучение проекта: каждый сбой или замечание становится уроком, который меняет правила и шаблоны проекта.
  Плагин при этом не меняется — улучшения к нему копятся как предложения и попадают в следующую версию.

## 4. Что от вас
Описать задачу словами, положить исходники в папку проекта, один раз утвердить критерии готовности, отвечать
на вопросы ведущего о недостающих данных (или сказать «нет данных» — он предложит обход) и решать только
«человеческие» вопросы: деньги, удаление, отправка наружу.

## 5. Чего Forge не делает
Не принимает решений за вас, не обещает цифр, которые не измерены, не выдаёт предположения за факты, ничего не
удаляет и не отправляет наружу без вашего «да», не работает по расписанию — только по вашей фразе.

## 6. Проверить, что всё работает (0 токенов, из папки проекта)
```
python <папка плагина>/tools/step.py
```
```
python <папка плагина>/gates/run_gates.py
```
Папку плагина ведущий печатает в первой строке при старте (`plugin: …`); для разработки это `C:\ai\agi\00_FORGE`.
